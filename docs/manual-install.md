# B站视频旋转：手动安装与使用教程

本文适用于无法或暂时不想通过 Microsoft Edge 加载项商店安装的用户。扩展基于 Chromium Manifest V3，可手动安装到 Microsoft Edge、Google Chrome 以及其他支持“加载已解压扩展”的 Chromium 浏览器。

## 一、安装前须知

- 手动安装不需要编程工具，也不需要运行任何命令。
- 浏览器不能直接加载下载的 `.zip` 压缩包，必须先把它完整解压。
- 手动安装后必须保持“开发人员模式/开发者模式”开启。关闭该模式后，浏览器会停用手动加载的扩展。
- 不要删除或移动安装时选择的扩展文件夹，否则浏览器下次启动时可能无法加载扩展。
- 从 Microsoft Edge 加载项商店安装的正式版本不需要开发者模式。

## 二、下载扩展

### 方法 A：下载发行压缩包（推荐）

1. 打开本项目的 [GitHub 仓库](https://github.com/zhenglinniao/bilibiliFlip)。
2. 进入仓库的 `dist` 文件夹。
3. 下载文件 `bilibili-video-rotate-edge-v1.0.1.zip`。
4. 在“下载”文件夹找到压缩包，右键选择“全部解压”或“解压到当前文件夹”。
5. 建议把解压后的文件夹移动到一个不会被清理的位置，例如：

   ```text
   C:\Users\你的用户名\Documents\BrowserExtensions\bilibili-video-rotate
   ```

### 方法 B：下载整个源代码仓库

1. 打开 [GitHub 仓库](https://github.com/zhenglinniao/bilibiliFlip)。
2. 点击绿色的 **Code** 按钮，再点击 **Download ZIP**。
3. 下载完成后右键压缩包，选择“全部解压”。
4. 打开解压得到的 `bilibiliFlip-main` 文件夹。

两种方法都可以使用。选择扩展目录时，请确认所选文件夹的第一层能直接看到 `manifest.json`，而不是还需要再进入一层文件夹。

正确结构示例：

```text
bilibili-video-rotate\
├─ manifest.json
├─ background.js
├─ content.css
├─ icons\
├─ popup\
└─ src\
```

如果打开所选文件夹后只能看到另一个同名文件夹，而看不到 `manifest.json`，说明选择的目录层级不正确，请进入下一层后再选择。

## 三、在 Microsoft Edge 中安装

1. 打开 Microsoft Edge。
2. 在地址栏输入下面的地址并按回车：

   ```text
   edge://extensions/
   ```

3. 打开页面左侧或右上角的 **开发人员模式** 开关。
4. 点击 **加载解压缩的扩展**。
5. 在文件选择窗口中，选择前面解压得到、直接包含 `manifest.json` 的文件夹，然后点击“选择文件夹”。
6. 扩展列表中出现“B站视频旋转”，且开关为开启状态，即表示安装成功。
7. 点击浏览器右上角的“扩展”拼图图标，在“B站视频旋转”旁点击小眼睛或固定按钮，把图标固定到工具栏。

Edge 可能显示“开发人员模式扩展”提示，这是手动安装扩展的正常提醒，不表示扩展损坏。请保留开发人员模式开启。

## 四、在 Google Chrome 中安装

1. 打开 Google Chrome。
2. 在地址栏输入下面的地址并按回车：

   ```text
   chrome://extensions/
   ```

3. 打开右上角的 **开发者模式**。
4. 点击左上角的 **加载已解压的扩展程序**。
5. 选择直接包含 `manifest.json` 的文件夹。
6. 扩展卡片中出现“B站视频旋转”后，点击工具栏的拼图图标并将它固定。

## 五、使用方法

1. 打开一个哔哩哔哩视频页面并等待播放器出现。
2. 点击工具栏中的“B站视频旋转”图标。
3. 点击 `0°`、`90°`、`180°` 或 `270°`，直接切换视频方向。
4. 也可以点击顺时针或逆时针按钮，每次旋转 90°。
5. 如需在刷新页面后继续使用上次的角度，请开启“记住上次角度”。

扩展只旋转视频画面，播放器按钮、弹幕层和网页布局会保持正常方向。旋转至 90° 或 270° 时，视频会自动缩放，以减少画面被裁切的情况。

默认快捷键：

- `Alt + Shift + R`：顺时针旋转 90°。
- `Alt + Shift + L`：逆时针旋转 90°。

如果快捷键与其他软件冲突，可以在以下页面修改：

- Edge：`edge://extensions/shortcuts`
- Chrome：`chrome://extensions/shortcuts`

## 六、在其他视频网站使用

扩展也可以尝试旋转其他网页中的标准 HTML5 `<video>` 视频：

1. 打开包含视频的网页。
2. 主动点击“B站视频旋转”图标。
3. 选择需要的旋转角度。

在非哔哩哔哩网站上，扩展只会在用户主动点击图标或使用快捷键后临时访问当前标签页。浏览器内部页面、扩展商店页面，以及不使用标准 HTML5 视频元素的网站可能无法旋转。

## 七、手动更新

手动安装的版本不会像商店版本一样自动更新。更新时请按以下步骤操作：

1. 重新下载最新的压缩包并解压。
2. 关闭正在使用扩展的网页。
3. 用新版本文件替换原安装文件夹中的旧文件。建议保持文件夹路径不变，这样浏览器通常可以继续识别原扩展及其本地设置。
4. 打开 `edge://extensions/` 或 `chrome://extensions/`。
5. 找到“B站视频旋转”，点击卡片上的 **重新加载** 按钮。
6. 重新打开视频页面并测试旋转功能。

如果更新后出现异常，可先在扩展管理页删除旧版本，再按照本文重新安装。重新安装可能会清除“记住上次角度”等本地设置。

## 八、常见问题

### 1. 提示“清单文件缺失或不可读取”

通常是文件夹选错了。请确认所选文件夹第一层直接包含 `manifest.json`，并确认压缩包已经完整解压。

### 2. “加载解压缩的扩展”按钮没有显示

请先打开扩展管理页中的“开发人员模式/开发者模式”开关。该按钮只会在开发者模式下出现。

### 3. 重启浏览器后扩展不能使用

检查开发者模式是否仍然开启、扩展开关是否启用，以及原来的扩展文件夹是否被移动、重命名或删除。

### 4. 工具栏找不到扩展图标

点击浏览器右上角的拼图图标，在扩展列表中找到“B站视频旋转”，然后点击固定图标。

### 5. 点击旋转没有反应

请依次尝试：

1. 等待视频播放器完全加载后再操作。
2. 刷新视频页面。
3. 在扩展管理页确认“B站视频旋转”已启用。
4. 点击扩展卡片上的“重新加载”，再刷新视频页面。
5. 确认当前页面不是 `edge://`、`chrome://`、浏览器扩展商店或其他禁止扩展运行的内部页面。

### 6. 画面旋转了，但方向或大小不合适

再次点击扩展图标并选择其他角度。90° 和 270° 会根据播放器空间自动缩放；某些网站使用特殊播放器结构，显示效果可能受到网页自身样式影响。

### 7. 浏览器提示手动扩展可能不安全

这是 Chromium 浏览器针对所有非商店扩展的通用安全提示。请只从本项目官方仓库下载文件，不要安装来源不明或被他人修改过的压缩包。你也可以直接查看仓库中的全部源代码。

## 九、卸载

1. 打开 `edge://extensions/` 或 `chrome://extensions/`。
2. 找到“B站视频旋转”。
3. 点击 **删除/移除** 并确认。
4. 确认不再需要后，可以删除电脑中保存的扩展文件夹和下载的压缩包。

卸载扩展只会删除扩展及其本地设置，不会修改或删除任何视频文件。

## 十、隐私与权限

- 所有旋转操作均在浏览器本地完成。
- 扩展不会下载、读取、保存或上传视频流。
- 扩展不收集个人信息、浏览历史、网页内容、账号信息或使用分析数据。
- `storage` 只保存用户选择的角度和“记住上次角度”设置。
- `activeTab` 与 `scripting` 只用于用户主动操作时在当前网页执行本地旋转逻辑。
- 对 `bilibili.com` 的访问权限用于适配播放器加载、切集、全屏和动态重建。

如需查看更完整的隐私说明，请阅读 [隐私政策](../store/privacy-policy-zh-CN.md)。
