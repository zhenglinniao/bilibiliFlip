# Microsoft Edge 商店文案（简体中文）

## 扩展名称

视频转转

## 短描述

一键旋转网页视频，支持 0°、90°、180°、270°，针对哔哩哔哩 Web 播放器优化。

## 详细描述

视频方向不对？“视频转转”可以直接旋转网页中的 HTML5 主视频，无需下载视频，也无需重新编码。打开视频页面后点击扩展图标，即可在 0°、90°、180° 和 270° 之间快速切换，也可以使用顺时针、逆时针按钮或键盘快捷键逐次旋转。

本扩展针对哔哩哔哩 Web 播放器进行了适配，支持普通播放、网页全屏、浏览器全屏以及切集后播放器重新加载等场景。旋转 90° 或 270° 时，画面会根据播放器尺寸自动缩放，尽量完整显示内容；扩展只处理视频画面，不会旋转播放器控制栏和网页布局。

除哔哩哔哩外，在使用标准 HTML5 `<video>` 元素的网站中，也可以点击扩展图标，将旋转功能临时应用到当前标签页。浏览器内部页面、扩展商店页面，以及使用 Canvas、WebGL 或封闭组件绘制视频的网站可能无法使用。

主要功能：

- 0°、90°、180°、270° 一键切换；
- 顺时针和逆时针逐次旋转；
- 90°/270° 自动适配播放器空间；
- 支持网页全屏和浏览器全屏；
- 支持记住上次角度；
- 支持自定义浏览器扩展快捷键；
- 所有处理都在本地完成，不上传视频，不收集浏览记录，不包含广告和远程代码。

默认快捷键：Alt + Shift + R 顺时针旋转，Alt + Shift + L 逆时针旋转。用户可以在 Edge 的扩展快捷键设置页面重新绑定快捷键。

“哔哩哔哩”和“B站”是其各自权利人的商标。本扩展是独立开发的第三方工具，与哔哩哔哩官方不存在隶属、合作或授权关系。
