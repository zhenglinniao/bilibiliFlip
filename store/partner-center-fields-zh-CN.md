# Partner Center 隐私与权限字段

以下内容可直接复制到相应表单字段。

## Single Purpose Description / 单一用途说明

本扩展仅用于按用户选择的角度旋转当前网页中的 HTML5 主视频画面，并针对哔哩哔哩 Web 播放器提供动态播放器与全屏场景适配。

## 权限说明

### `activeTab`

当用户点击扩展图标或触发扩展快捷键时，临时访问当前标签页，以便在非哔哩哔哩网站中查找并旋转用户正在观看的 HTML5 视频。权限仅由明确的用户操作触发。

### `scripting`

用于在用户主动操作的当前标签页中注入本地打包的旋转脚本和样式。扩展不下载或执行远程代码。

### `storage`

仅用于在用户本地浏览器中保存“是否记住上次角度”和最近选择的旋转角度。数据不会离开用户设备。

### `*://*.bilibili.com/*` 与 `*://bilibili.com/*`

用于在哔哩哔哩 Web 播放器加载、单页导航、切集或重建播放器后持续识别主视频元素并应用用户选择的旋转角度。这是扩展重点支持的网站范围。

## Remote code / 远程代码

选择：**No / 否**。

说明：所有 JavaScript、CSS、HTML 和图片均随扩展包本地提供。扩展不会下载、引用或执行远程代码。

## Data usage / 数据使用

选择：**不收集任何用户数据**。

补充说明：扩展不收集或传输个人信息、浏览历史、视频内容、页面内容、Cookie、账号信息、输入内容、分析数据或诊断数据。仅在浏览器本地保存用户的旋转偏好。

## 建议可见性

- 希望任何用户都能搜索安装：`Public`。
- 仅打算通过链接分享：`Hidden`。

两种方式均由 Edge 加载项商店托管和安装，不要求用户开启开发者模式。
