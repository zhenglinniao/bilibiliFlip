# 提交审核说明

以下内容可复制到 Partner Center 的 Notes for certification。

## 中文版本

本扩展无需账号、登录、订阅或付费功能。

建议测试步骤：

1. 在 Microsoft Edge 中安装扩展。
2. 打开任意哔哩哔哩公开视频页面并开始播放。
3. 点击工具栏中的“B站视频旋转”图标。
4. 分别点击 90°、180°、270° 和 0°，确认视频画面改变方向，播放器控制栏和网页布局不旋转。
5. 点击“顺时针”和“逆时针”，确认每次旋转 90°。
6. 进入网页全屏或浏览器全屏，确认旋转保持有效。
7. 开启“记住上次角度”，刷新页面，确认角度恢复。
8. 可选：打开另一个使用标准 HTML5 video 元素的网站，点击扩展图标后确认旋转可用。

扩展不连接任何服务器，不收集或传输用户数据，不包含远程代码。浏览器内部页面、Edge 加载项商店页面，以及未使用标准 HTML5 video 元素的网站不在支持范围内。

## English version

This extension requires no account, sign-in, subscription, or payment.

Suggested test steps:

1. Install the extension in Microsoft Edge.
2. Open any publicly accessible Bilibili video and start playback.
3. Click the “B站视频旋转” toolbar icon.
4. Select 90°, 180°, 270°, and 0°. Verify that only the video image rotates while the player controls and page layout remain upright.
5. Test the clockwise and counterclockwise buttons; each action rotates the video by 90°.
6. Enter web fullscreen or browser fullscreen and verify that rotation remains active.
7. Enable “Remember last angle,” reload the page, and verify that the angle is restored.
8. Optional: on another website using a standard HTML5 video element, invoke the extension and verify that rotation works in the active tab.

The extension makes no network connections, collects or transmits no user data, and contains no remotely hosted code. Browser internal pages, the Edge Add-ons store, and websites that do not use standard HTML5 video elements are outside the supported scope.
